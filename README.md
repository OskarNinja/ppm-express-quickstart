# PPM Express Quick Start

Static, self-hostable landing page for GitHub Pages and embedding in PPM Express.

## Publish with GitHub Pages
1. Upload the contents of this folder to a repository.
2. In **Settings > Pages**, deploy from the branch containing `index.html`.
3. Use the published GitHub Pages URL in the PPM Express embed/landing-page configuration.

All destination links open in a new tab. Temporary role and tool URLs are centralised in `index.html` and can be replaced later.
